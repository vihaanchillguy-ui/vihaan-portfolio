# Vihaan's Portfolio

A responsive personal portfolio, project showcase, blog and support page.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait a minute or two for the site to publish.

Your site URL will be:

https://vihaanchillguy-ui.github.io/vihaan-portfolio/

## Customise it

- Edit project names and links in `index.html`.
- Add or edit blog notes in the `posts` array in `script.js`.
- Update colours and layout in `styles.css`.
- The donation button is intentionally inactive until a legitimate payment link is arranged with a parent or guardian. No payment information is collected by this site.

The site is plain HTML, CSS and JavaScript. No build tools or paid hosting required.
